
# Sales Analytics

## Description
This project is a sales analytics database built with PostgreSQL.

The goal is to practice SQL, database design, data relationships and analytical queries.

## Technologies
- PostgreSQL
- SQL
- Visual Studio Code
- Git

## Project structure
- sql/: SQL scripts
- README.md: Project documentation

## Learning objectives
- Create relational tables
- Define primary and foreign keys
- Practice SQL queries
- Use INNER JOIN and LEFT JOIN
- Analyze sales data
